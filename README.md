# Flappy Seb

Un jeu d'adresse parfaitement déraisonnable : Seb bat des bras, traverse des murs, affronte des boss et enchaîne dix-huit mini-jeux.

Jouer : https://valoutre.github.io/flappy-seb/

## Organisation

- `index.html` : le jeu, en un seul fichier (source publiée en artefact, sans en-tête HTML).
- `docs/index.html` : la page servie par GitHub Pages, régénérée par `tools/pages.sh`.
- `firestore.rules` : règles de sécurité du classement en ligne (Firebase Firestore).
